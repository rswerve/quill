# Quill v1.1.17

**Line breaks no longer eat the space between your words.**

This release fixes a Markdown parsing defect that silently destroyed whitespace — and, on repeated saves, could destroy formatting outright.

- **Soft breaks after bold, italic, code, or struck text keep their space.** A document written as

  ```markdown
  **THE OPPORTUNITY:**
  A position with Truss...
  ```

  opened with the words jammed together (`**THE OPPORTUNITY:**A position...`) and saved that way. A single newline inside a paragraph is a CommonMark _soft break_, which means an ordinary space; Quill was dropping it whenever it followed an inline mark. Plain text was unaffected, which is why this went unnoticed.

- **The damage compounded across saves.** Once the separator was gone, the emphasis delimiter no longer parsed on the next open, and the following save escaped it into literal `\*\*` — permanently losing the bold. Files could degrade a step further every time they were saved.

- **Hard breaks are untouched.** Explicit two-space and backslash line breaks still produce real line breaks. Lists, blockquotes, and tables round-trip as before.

**If you have an affected document,** reopening it in this version will not restore the lost spaces — the previous version already wrote the damage to disk. Search for words running together at the start of a paragraph (`**HEADING:**Word`) and re-insert the space once; it will stay fixed from here.

No file-format or data changes. Documents, comments, suggestions, chat threads, and linked sessions carry over unchanged.

## Install

Inside Truss, Quill is shared as a ready-to-run app on the team's Google Drive — copy `Quill.app` from the shared drive (in Finder, from your synced folder) to your Applications folder and open it. The [README](../../README.md#installing-quill) has the details and the [User Guide](../USER_GUIDE.md) a full walkthrough. The Claude features require the [Claude Code](https://claude.com/claude-code) CLI on the same Mac.

## Known limitations

- macOS only. Not yet Apple-notarized — a copy downloaded through a browser (e.g. the Drive website) is typically quarantined and trips Gatekeeper on first launch; open the Finder-synced copy instead, or use **System Settings → Privacy & Security → Open Anyway**.
- Single-user: multiple documents open as tabs in one window; no multi-user collaboration or cloud sync.
- Suggesting mode cannot yet merge, split, or restructure blocks as a tracked change — Quill will tell you when a request needs Editing mode.
