# v1.1.19

**Two fixes to things you look at.** Nothing about your documents, comments, track-changes, or the
Claude integration changes.

## What changed

- **Find now scrolls to what it found.** Searching with ⌘F highlighted every match and counted them
  correctly, but the page never moved — so any match below the fold stayed off-screen and you had
  to scroll hunting for it yourself. Stepping through results, typing a query, and stepping past a
  replacement all bring the current match into view now, centred in the page.

- **Chat text is bigger.** The message text in the Chat panel was small enough to be uncomfortable
  for anything longer than a sentence. Messages, the composer, and the empty-state prompt are now
  set at a comfortable reading size. The small labels around them — the Claude name, the ⌘↵ hint,
  the chips and buttons — deliberately stay small, so the panel reads as text with quiet controls
  rather than uniformly larger everything.

Update the same way as always: quit Quill, then drag `Quill.app` from the synced Drive folder into
`/Applications`, replacing the old copy. Documents and settings carry over.
