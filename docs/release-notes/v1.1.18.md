# Quill v1.1.18

**Accept All now tells you what it couldn't do.**

When a structure change can't be resolved, Accept All falls back to resolving suggestions one at a time — and it used to drop some of them without a word. You asked for all, got some, and nothing on screen said otherwise.

- **Accept All and Reject All report themselves.** If anything is left behind, you now get a plain account: how many were applied out of how many, and why the rest weren't. Silence is reserved for the case where everything actually succeeded.

- **A blocked comment no longer discards a good edit.** When Claude's edit came from a comment, accepting it also closes that comment thread. Previously, if the _thread_ couldn't be closed — because a pending structure change overlapped it — Quill threw away the whole edit, even though applying the edit itself was perfectly safe. Now the edit is applied and the thread is simply left open for you, and the notice says so.

- **Genuinely unsafe changes are still skipped, but visibly.** A suggestion whose own edit would write inside a pending structure change can't be applied without corrupting it. That one is still held back — the difference is you're told, instead of being left to notice a suggestion that quietly survived a gesture that claimed to resolve everything.

The count in that message is the number of comment threads, not the number of changes: several suggestions that all trace back to one comment leave one thread open, and the notice says one.

No file-format or data changes. Documents, comments, suggestions, chat threads, and linked sessions carry over unchanged.

## Install

Inside Truss, Quill is shared as a ready-to-run app on the team's Google Drive — copy `Quill.app` from the shared drive (in Finder, from your synced folder) to your Applications folder and open it. The [README](../../README.md#installing-quill) has the details and the [User Guide](../USER_GUIDE.md) a full walkthrough. The Claude features require the [Claude Code](https://claude.com/claude-code) CLI on the same Mac.

## Known limitations

- macOS only. Not yet Apple-notarized — a copy downloaded through a browser (e.g. the Drive website) is typically quarantined and trips Gatekeeper on first launch; open the Finder-synced copy instead, or use **System Settings → Privacy & Security → Open Anyway**.
- Single-user: multiple documents open as tabs in one window; no multi-user collaboration or cloud sync.
- Suggesting mode cannot yet merge, split, or restructure blocks as a tracked change — Quill will tell you when a request needs Editing mode.
