# Quill v1.1.22

**Maintenance release. The editor and desktop foundations are current, with no workflow changes.**

## What changed

- Updated the editor, desktop runtime, and build tooling, including fixes for known dependency
  security issues.
- Markdown lines made only of non-breaking spaces now survive save and reopen instead of becoming
  empty. Quill rechecks existing comment and suggestion anchors conservatively the first time an
  older sidecar is opened under the updated Markdown behavior.

Documents, comments, suggestions, chat threads, and linked sessions remain compatible.

## Install

Quill can install this update from its update prompt or **Help → Check for Updates**. To update
manually, quit Quill and replace the copy in Applications with `Quill.app` from the synced Truss
Drive folder. Documents and settings carry over.
