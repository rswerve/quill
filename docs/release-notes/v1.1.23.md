# Quill v1.1.23

**Maintenance release with safer Claude sessions, clearer update failures, and fixes for literal text.**

## What changed

- **Start new session** no longer loads the document folder's project or local Claude Code
  configuration, including hooks, environment settings, MCP servers, skills, commands, agents,
  and instructions. A linked reference folder's skills, commands, and agents are also excluded.
  User-level configuration and Quill's effort hook still apply. Sessions linked from the picker
  keep their project's configuration.
- Quill-created sessions follow the document's new folder after **Save As**, including retries.
  The conversation continues, while its transcript stays in the original folder's session store.
  The configuration and Save As behaviours were verified only with Claude Code CLI **2.1.302**.
- If you set `CLAUDE_CONFIG_DIR` in Quill's environment, use an absolute path or unset it. Empty
  and relative values now produce an error before Quill reads sessions or starts Claude.
- Cancelling a Claude request or quitting Quill normally stops the request's background
  processes. Closing a tab cancels its request and prevents delayed requests from starting.
- Updates are staged and checked before Quill closes. Failures provide clearer recovery
  guidance, and successful in-app updates retain one previous build. Signature checks verify
  integrity; they do not identify the publisher.
- Find and Replace and AI suggestions preserve literal replacement text, including text that
  looks like HTML. Text that looks like Markdown entities survives save and reopen.
- Updated affected build and test dependencies, with a patched Node 22 minimum for contributors.

Documents, comments, suggestions, chat threads, and linked sessions remain compatible.

## Install

Quill can install this update from its update prompt or **Help → Check for Updates**. To update
manually, quit Quill and replace the copy in Applications with `Quill.app` from the synced Truss
Drive folder. Documents and settings carry over.
